## Desain audio
- **VO:** neural TTS Indonesia, jeda antar-kalimat dikompres otomatis ke ~0,3 dtk + jeda dramatis terkontrol (`||`) di titik ketegangan.
- **Musik orisinal (prosedural, bebas hak cipta):** 100 BPM. Hook = drone Dm + detak jam; peta = arpeggio + kick; cara kerja = progresi terang F–C–Dm–B♭; plot twist = stop + riser + impact; konspirasi = Dm–B♭–Gm–A + detak jam; sisi gelap = drone + detak jantung; penutup = B♭–C–F–Dm. Musik di-*duck* otomatis −6 dB saat VO bicara.
- **SFX tersinkron event visual:** pop saat callout muncul, dua nada untuk tag, swish+ding untuk kartu, impact untuk panel judul, whoosh untuk transisi awan, gemuruh + ratusan "klak" saat ubin runtuh, hujan, bor, semburan uap, dengung turbin 50 Hz, zap listrik, api boiler, rantai & dentum timbangan, alarm H₂S, gemuruh gempa, tik penghitung angka.
- **Loudness:** −14 LUFS (standar TikTok), true-peak −1,5 dBTP.
